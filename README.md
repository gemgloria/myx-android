# MYX 1.2.0

离线安卓中国象棋应用及悬浮助手，适用于 Android 8.0+、ARM64。棋盘识别适配原有木纹皮肤，使用本地 Pikafish 计算，通过安卓屏幕捕获与无障碍手势接口识别、落子。

本版接入官方 Pikafish **2026-09-06** 的源码及配套 NNUE。上游提交、发布包和模型校验值固定在 [vendor-manifest.json](vendor-manifest.json)。

| 设置 | 默认值 | 可选值 |
|---|---|---|
| 悬浮助手搜索线程 | 4，受可用处理器数限制 | 1 / 2 / 4 |
| 搜索缓存 | 256 MB，低内存设备使用 128 MB | 128 / 256 / 512 MB |
| 对手回合预先思考 | 开启 | 开启 / 关闭 |
| 随机思考时间 | 随机2 | 随机2：0.8 / 1 / 1.2 / 1.5 秒；随机1：1 / 3 / 5 秒 |

预先思考分析已确认的当前局面，利用引擎缓存供后续搜索参考。对手实际落子后停止分析，按实际棋谱重新计算；分析结果不会直接用于点击。暂停、识别中断或离开目标窗口时停止计算。持续计算会增加耗电和发热，可在“选项”关闭。

保留 MYX 标题、重开与暂停的位置调整、标题下方的胜棋／和棋／输棋估计、选中棋子识别及自动重试。概率来自引擎评估，不代表对局结果保证。识别模板只覆盖已适配的棋盘皮肤。

源码构建方式见 [BUILDING.md](BUILDING.md)。GitHub Actions 生成未签名 APK；覆盖升级需要在本地使用原签名。签名私钥、密码和用户截图均不在仓库内。
